┌─────────────────────────────────────────────────────────────────────────────┐
│ 📝 FICHIER .env À CRÉER                                                     │
└─────────────────────────────────────────────────────────────────────────────┘

Créez un fichier .env à la racine avec ce contenu :

# PostgreSQL
POSTGRES_DB=sahabi_db
POSTGRES_USER=sahabi
POSTGRES_PASSWORD=CHANGEZ_MOI_EN_PRODUCTION
POSTGRES_PORT=5432

# Keycloak
KEYCLOAK_ADMIN=admin
KEYCLOAK_ADMIN_PASSWORD=CHANGEZ_MOI_EN_PRODUCTION
KEYCLOAK_HOSTNAME=localhost
KEYCLOAK_PORT=8080

# Backend
BACKEND_PORT=8084
SPRING_PROFILE=prod
APP_SECURITY_ENABLED=true

# Frontend
FRONTEND_PORT=3000

# JWT
JWT_SECRET=CHANGEZ_MOI_PAR_UNE_LONGUE_CHAINE_ALEATOIRE_TRES_SECURISEE

# Production (si applicable)
DOMAIN=votre-domaine.com
ACME_EMAIL=votre-email@domaine.com
TAILSCALE_AUTHKEY=tskey-...


┌─────────────────────────────────────────────────────────────────────────────┐
│ 🚀 COMMANDES DE DÉPLOIEMENT                                                 │
└─────────────────────────────────────────────────────────────────────────────┘

1. Copier tous les fichiers obligatoires sur le serveur
2. Créer le fichier .env
3. Exécuter :

   docker-compose build
   docker-compose up -d

4. Vérifier :

   docker-compose ps
   docker-compose logs -f
