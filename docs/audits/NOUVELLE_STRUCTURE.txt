───────────────────────────────────────────────────────────────────────────
 🚀 COMMANDES ESSENTIELLES (Windows)
───────────────────────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────────────────────┐
│  DÉMARRER LE PROJET                                                 │
└─────────────────────────────────────────────────────────────────────┘

  .\scripts\docker\start.ps1

  ✅ Démarre tous les services Docker
  ✅ Accès : http://localhost:3000 (admin / admin123)


┌─────────────────────────────────────────────────────────────────────┐
│  EXPOSER SUR INTERNET (Tailscale)                                   │
└─────────────────────────────────────────────────────────────────────┘

  1. Obtenir une clé sur : https://login.tailscale.com/admin/settings/keys
  
  2. Déployer :
     .\scripts\deployment\deploy-internet.ps1 -Mode tailscale -TailscaleKey "tskey-..."
  
  3. Configurer Serve (nouvelle syntaxe) :
     docker exec sahabi-tailscale tailscale serve --bg http://frontend:80
     docker exec sahabi-tailscale tailscale serve status


┌─────────────────────────────────────────────────────────────────────┐
│  VOIR LES LOGS                                                      │
└─────────────────────────────────────────────────────────────────────┘

  docker-compose logs -f              # Tous les services
  docker-compose logs -f backend      # Backend uniquement
  docker-compose logs -f frontend     # Frontend uniquement


┌─────────────────────────────────────────────────────────────────────┐
│  ARRÊTER                                                            │
└─────────────────────────────────────────────────────────────────────┘

  docker-compose down                 # Arrêt normal
  docker-compose down -v              # Arrêt + Suppression données
